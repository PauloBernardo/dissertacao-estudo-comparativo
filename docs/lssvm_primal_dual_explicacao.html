LSSVM Padrão: Primal e Dual

A ideia aqui é simples: o primal pensa em "aprender o classificador diretamente", enquanto o dual pensa em "aprender quanto cada amostra de treino contribui para o classificador".

1. A função que queremos aprender

f(x) = w^T phi(x) + b

Tradução humana: para classificar um novo ponto x, o modelo calcula uma pontuação f(x).

SímboloSignificado simples
xUm exemplo de entrada. Ex.: uma linha da tabela com as features.
f(x)A pontuação final do modelo para o ponto x.
wO vetor de pesos do classificador. É o "miolo" da reta/plano de decisão.
w^TÉ só uma forma de escrever produto interno. Pode ler como "w combinado com".
phi(x)Uma versão transformada de x. O kernel finge que existe essa transformação sem calcular tudo explicitamente.
bBias/intercepto. Um ajuste constante somado no final.

2. Onde está o primal

Primal

No primal, as variáveis principais são:

w, b, e

Ou seja, o problema original tenta encontrar:

  • w: os pesos do classificador
  • b: o bias
  • e_i: os erros/slacks de cada amostra
Primal
min 1/2 ||w||² + (gamma/2) sum e_i²

Tradução:

  • min = queremos minimizar
  • ||w||² = tamanho de w; o modelo prefere pesos menores
  • gamma = controla o peso dado aos erros
  • sum e_i² = soma dos erros ao quadrado

3. As restrições do primal

y_i ( w^T phi(x_i) + b ) = 1 - e_i
SímboloSignificado simples
x_iA i-ésima amostra de treino.
y_iO rótulo da i-ésima amostra, normalmente -1 ou +1.
e_iErro da amostra i.
iÍndice da amostra. Se houver 3 pontos, então i=1,2,3.

A ideia é: cada ponto de treino deveria ficar do lado certo da fronteira. Se não ficar, entra um erro e_i.

4. Onde nasce o dual

Para lidar com as restrições, introduzimos um multiplicador de Lagrange para cada amostra:

alpha_1, alpha_2, alpha_3, ..., alpha_n

Esses alpha_i são os pesos das amostras no dual.

Intuição: no primal você aprende w. No dual você aprende "quanto cada exemplo de treino entra na construção de w".

5. A virada principal

Quando resolvemos as condições do problema, aparece a relação:

w = sum alpha_i y_i phi(x_i)

Isso significa:

  • w não precisa mais ser achado diretamente
  • w vira uma combinação das amostras de treino
  • agora basta descobrir os alpha_i

6. O kernel entra aqui

No dual, aparecem produtos entre pontos transformados:

K(x_i, x_j) = phi(x_i)^T phi(x_j)
SímboloSignificado simples
K(x_i, x_j)Medida de semelhança entre as amostras x_i e x_j.
KMatriz kernel inteira, contendo as semelhanças de todos contra todos.
K = [ K(x1,x1) K(x1,x2) K(x1,x3) ] [ K(x2,x1) K(x2,x2) K(x2,x3) ] [ K(x3,x1) K(x3,x2) K(x3,x3) ]

7. Onde está o dual no LSSVM padrão

Dual

No LSSVM padrão, o solver costuma resolver um sistema linear em alpha e b.

resolver: alpha e b

Ou seja:

  • o problema começou no primal
  • mas a solução prática é obtida no dual

8. Predição no dual

f(x) = sum alpha_i y_i K(x_i, x) + b

Tradução: para classificar um novo ponto x, o modelo:

  1. compara x com cada ponto de treino via kernel
  2. multiplica cada comparação por alpha_i y_i
  3. soma tudo
  4. adiciona b

9. Fluxo completo

Fase 1: definir o modelo: f(x) = w^T phi(x) + b
↓
Fase 2: escrever o problema original em w, b, e → isso é o primal
↓
Fase 3: introduzir multiplicadores alpha_i
↓
Fase 4: eliminar w e reescrever tudo em termos de kernel e alpha
↓
Fase 5: resolver o sistema em alpha, b → isso é o dual
↓
Fase 6: prever com f(x) = sum alpha_i y_i K(x_i,x) + b

10. Frase para guardar

Primal: aprende o classificador pelos pesos w.

Dual: aprende o classificador pelos pesos das amostras, alpha_i.
